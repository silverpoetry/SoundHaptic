# 兼容性与已知限制

## 证据等级

| 等级 | 含义 |
|---|---|
| 实机验证 | 在指定设备和 ROM 上确认能力、最终入口、播放与关键系统动作 |
| 结构兼容 | 私有类和签名相同，但尚未完成完整动作矩阵 |
| 推测 | 只根据相近 ROM 或公开结构判断，不应写成“支持” |

## 当前矩阵

| 设备/系统 | 等级 | 说明 |
|---|---|---|
| `sheng` / `24018RPACC` / HyperOS Android 16 | 实机验证 | 返回、应用/输入法标准触感、锁屏、通知与最近任务清理路径参与开发验证 |
| 其他 Android 16 HyperOS 平板 | 推测 | 可能复用框架结构；MIUI 扩展 ID、类签名和扬声器响应可能不同 |
| AOSP Android | 未支持 | 没有 MIUI 私有能力与扩展语义；当前作用域和验证目标不覆盖 |
| Android 15 及以下 HyperOS/MIUI | 未支持 | `VibratorManagerService` 和私有接口签名可能不同 |
| 自带物理振动器设备 | 非目标 | 模块会虚拟化能力并额外播放声音，不建议启用 |

## 动作矩阵

| 请求来源 | 处理路径 | 预期 |
|---|---|---|
| 普通应用 `Vibrator` / `VibratorManager` | `system_server` 原始最终入口 | 从 effect/segment 恢复语义后播放 |
| `View.performHapticFeedback` | 平台语义最终入口 | 按 HapticFeedback constant 映射 |
| 输入法 | 平台语义或原始入口 | 区分按下、释放、刻度或点击 |
| SystemUI/桌面 MIUI 扩展 | `HapticFeedbackUtil` 终点 | 按 key 或扩展 ID 映射 |
| 锁屏扩展 ID 209 | MIUI 终点 | 双段锁定节奏 |
| 通知清理扩展 ID 212 | MIUI 终点 | 多段渐弱节奏 |
| 最近任务清理扩展 ID 213 | MIUI 终点 | 多段渐弱节奏 |
| ROM 从未发出触感请求的动作 | 无入口 | 模块不会按按钮名称人工补触感 |

## 已知限制

- 扬声器的低频效率、安装方式和机身共振决定实际触感，参数不能跨机型照搬；
- 252 Hz 是目标平板的听感选择，不表示其扬声器物理共振点经过仪器测量；
- 极短 PCM 脉冲仍可能被音频 HAL、功放淡入或路由切换改变；
- 强制内置扬声器依赖 Android 音频设备路由，ROM 实现异常时应停止使用；
- 截屏在当前 ROM 上没有稳定的最终触感请求，因此未增加业务 Hook，也未加入作用域；
- 息屏期间系统可能限制音频；模块只在正常生命周期内预热和恢复，不维持无限后台播放；
- Protective Hook 能避免异常直接传播，但无法保证所有魔改 ROM 都不会出现系统进程问题。
